# DualBuild

Aplicación de construcción virtual en 3D con piezas modulares, manipuladas con gestos de ambas manos capturados por una cámara y procesados con visión por computadora. Permite seleccionar, agarrar, desplazar, rotar y ensamblar piezas sin depender del teclado ni del ratón.

DualBuild tiene identidad y sistema de piezas propios y no es un producto oficial de LEGO.

Este repositorio contiene la **documentación del proyecto**, organizada por etapas del ciclo del proyecto de inversión.
